# Benutzerhandbuch

## Manager Tabs

Das Modul enthalt Tabs fur Articles, Autoren, Tags, Kommentare, Umfragen, Themen, Merkmale, Parameter (TV) und Konfiguration.

Die Tabs laufen uber Livewire. Beim Wechsel wird nur der Modulinhalt aktualisiert.

## Listen

Die meisten Listen bieten Tabellen- und Listenmodus, Suche, Sortierung, Pagination, Zeilenanzahl und Zeilenaktionen. Die Artikelliste hat zusatzliche Filter fur Bereich, Tags, Themen, Merkmale, Datum, Status und Typ.

## Publikation bearbeiten

Die Bearbeitung erfolgt in einem groBen Modal. Der Haupttab enthalt Titel, Langtitel, Zusammenfassung, Alias, Beschreibung, Hauptbild, Bildtitel, Status, Datum, Bereich, Autor, Position und Beziehungen.

Der Content-Tab enthalt den Builder. Wenn sLang aktiv ist, werden Tabs pro Sprache angezeigt.

## Builder

Verfugbare Blocke: RichText, SingleImg, Image and Text, YouTube, Quote, Note, ArticlePreview, Poll, Slider, Accordion und File.

## Einstellungen

In der Konfiguration konnen Basisfunktionen, Manager-Menu, Editor und Publikationstypen verwaltet werden.

Der erste Typ `article` ist geschutzt. Weitere Typen konnen nur geloscht werden, wenn keine Publikationen diesen Typ verwenden.

## Editor

Die Option **Editor**:

- **System** - nutzt EVO `which_editor`.
- **eTinyMCE** - erzwingt eTinyMCE in sArticles.
- **dTuiEditor** - erzwingt dTui.editor in sArticles.
- Jeder registrierte EVO Editor.

## SEO und Sprachen

sSeo fugt SEO-Felder hinzu. sLang aktiviert sprachbezogene Tabs und speichert Ubersetzungen separat.
