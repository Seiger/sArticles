# Руководство пользователя

## Вкладки

Модуль содержит вкладки: Articles, Авторы, Теги, Комментарии, Опросы, Тематики, Особенности, Параметры (TV), Конфигурация.

Все основные вкладки работают через Livewire. При переключении обновляется только содержимое модуля.

## Списки

В списках доступны таблица и список, поиск, сортировка, пагинация, выбор количества строк и действия над строками. В публикациях есть фильтры по разделу, тегам, тематикам, особенностям, дате, статусу и типу публикации.

## Публикация

Форма открывается в большой модалке. Основная вкладка содержит заголовок, расширенный заголовок, аннотацию, псевдоним, описание, изображение, тайтл изображения, статус, дату, раздел, автора, позицию и связи.

Вкладка контента содержит builder. При включенном sLang вкладки строятся по языкам.

## Builder

Доступны блоки RichText, SingleImg, Image and Text, YouTube, Quote, Note, ArticlePreview, Poll, Slider, Accordion и File.

## Настройки

В конфигурации можно включать и выключать базовые функции, управлять отображением модуля в меню, выбирать rich editor и редактировать типы публикаций.

Тип `article` защищен. Другие типы можно удалить только если нет публикаций такого типа.

## Редактор

Параметр **Редактор**:

- **Системный** - использует EVO `which_editor`.
- **eTinyMCE** - включает eTinyMCE для sArticles.
- **dTuiEditor** - включает dTui.editor для sArticles.
- Любой другой зарегистрированный EVO редактор.

## SEO и языки

sSeo добавляет SEO-поля. sLang включает языковые вкладки и сохраняет переводы отдельно.
