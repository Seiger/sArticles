# Документація sArticles

sArticles - модуль Evolution CMS для керування публікаціями, новинами, блогом, коментарями, опитуваннями, авторами, тегами, тематиками, особливостями та TV-параметрами публікацій.

Поточний інтерфейс менеджера побудований на **evo-ui** та **Livewire**. Модуль працює як компактний SPA всередині менеджера Evolution: вкладки, фільтри, пагінація, сортування, режим таблиці/списку, модалки та редактори оновлюються без повного перезавантаження iframe.

## Основні можливості

- Список публікацій у режимах таблиці та списку.
- Пошук, сортування, фільтри, діапазон дат, фільтр доступності та пагінація.
- Налаштовувані типи публікацій.
- Велика модалка редагування з основними полями, зв'язками, мультимовністю, SEO та builder-контентом.
- Блоки builder: RichText, SingleImg, Image and Text, YouTube, Quote, Note, ArticlePreview, Poll, Slider, Accordion, File.
- Керування авторами, тегами, текстами тегів, тематиками, особливостями, коментарями, опитуваннями та TV.
- Нативні інтеграції з sSeo та sLang.
- Вибір rich editor для sArticles: системний, eTinyMCE, dTuiEditor або інший зареєстрований EVO редактор.

## Важливі файли

- `config/sArticlesSettings.php` - дефолтні налаштування.
- `config/settings/form.php` - форма налаштувань.
- `config/articles/table.php` - пресет таблиці публікацій.
- `config/articles/modal.php` - пресет модалки публікації.
- `src/Tables/ArticlesTableData.php` - дані, збереження та логіка публікацій.
- `src/Support/SeoIntegration.php` - інтеграція з sSeo.
- `src/Support/LangIntegration.php` - інтеграція з sLang.
- `builder/*` - блоки конструктора контенту.
